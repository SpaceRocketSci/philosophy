# Pages CMS

Pages CMS е React приложение с Tailwind CSS. Интерфейсът и публичният сайт се изграждат като статични файлове за GitHub Pages. API-то и SQLite базата работят отделно на хостинг с Node.js и постоянен диск.

CMS профилите са локални (имейл и парола). Редакторите и администраторите не се вписват с GitHub. За автоматично публикуване администраторът на репозиторията добавя един ограничен GitHub token като тайна само на API сървъра.

## Публикуване в GitHub Pages

В репозиторията отвори **Settings → Pages** и за източник избери **GitHub Actions**. Добави repository variable `VITE_API_URL` със стойността на публичния HTTPS адрес на API-то, например `https://cms-api.example.com` (без наклонена черта накрая). Workflow-ът `.github/workflows/pages.yml` изгражда и публикува интерфейса при push към `main`.

Одобрена страница се експортира към `web/public/content.json` през GitHub Contents API. Този commit задейства ново изграждане на Pages. Публичният сайт се намира на `/philosophy/site/`; страниците се отварят като `.../site/#slug`. За repository Pages адресът е `https://spacerocketsci.github.io/philosophy/`.

GitHub Pages е статичен хостинг: затова Node API-то и базата са отделни услуги. [GitHub Pages описание](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

## API сървър

Разположи Node.js 20+ сървъра на хостинг, който дава публичен HTTPS адрес и постоянен диск/volume. Запази `data/` и `uploads/` между рестартиранията. Клонирай репозиторията и изпълни `npm install --omit=dev`. Задай environment variables по `.env.example` в control panel-а на хостинга; не качвай `.env` или GitHub token в репозитория.

Нужен е fine-grained personal access token, ограничен до репозитория `SpaceRocketSci/philosophy`, с `Contents: write`. Token-ът остава само при API сървъра; администраторите и редакторите на CMS не го използват. GitHub изисква `Contents: write`, за да създава или обновява файла с одобреното съдържание. [GitHub Contents API](https://docs.github.com/en/rest/repos/contents)

Задай `CMS_ORIGINS=https://spacerocketsci.github.io` (origin-ът без `/philosophy`) или точния origin на custom domain. В production зад reverse proxy използвай HTTPS. Силно и различно `SESSION_SECRET`, `API_SECRET` и `OWNER_PASSWORD` са задължителни. `OWNER_EMAIL` трябва да е имейл, който GitHub приема като committer.

Локална разработка: `npm install`, после в два терминала `npm run api:dev` и `npm run dev`.

## Редактор и визуална система

- **WYSIWYG**: rich text с заглавия, bold/italic/underline/strike, списъци и чеклистове, цитати, inline/block code, линкове, качване на изображения, таблици, цвят, highlight, горен/долен индекс, подравняване, undo/redo и брояч на думи/символи.
- **IDE / HTML режим**: CodeMirror с подсветка, номерация на редове и сгъване на HTML/CSS/JavaScript. Темите се пишат с CSS, шаблоните с HTML.
- **Конфигурация от CMS**: собственикът включва/изключва WYSIWYG инструментите в Настройки; конфигурацията се пази в базата.
- **Анимации**: React интерфейсът използва Motion за преходи и появяване на панели. В WYSIWYG има анимации за блокове; публичният сайт прилага fade, slide и zoom ефекти с `prefers-reduced-motion` поддръжка. Собствените теми могат да задават допълнителни CSS анимации.

Текстовото съдържание се пречиства преди публичния експорт, а HTML на шаблона се филтрира. CSS темите са код, написан от администратор/собственик, и се изнасят както са въведени.

## Панели и роли

- **Страници** — редакция в WYSIWYG или HTML IDE, чернови, статус, шаблон и коментари по собствени и чужди страници.
- **За одобрение** — редактор изпраща заявка; собственикът или администраторът преглежда, коментира, иска промени, или одобрява и публикува.
- **Общ чат** — екипийн чат, синхронизиран през API.
- **Медийна библиотека** — изображения/PDF.
- **Теми и шаблони** — CSS/HTML редактори в браузъра.
- **Потребители и настройки** — локални профили, ролеви достъп и конфигурация на редактора.
